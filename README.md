# Game — Web + Node Game Projects

A small collection of web game frontends and a minimal Node.js API backend. Includes two React frontends (one Vite-based, one Create React App) and a lightweight Express API used for development and local testing. Intended for developers who want to run and extend a browser-based game (the Vite app is named `chess-project` in the repo).

## Stack
- Language(s): JavaScript (primary), HTML, CSS
- Frameworks / runtimes: React (Vite app + Create React App), Node.js + Express
- Notable libraries: react, react-dom, vite, express, cors, firebase, react-router-dom
